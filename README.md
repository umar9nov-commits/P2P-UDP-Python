
# Decentralized P2P Group Chat and File Sharing Using UDP

## Project Overview

This project implements a decentralized peer-to-peer (P2P)
communication system using Python and UDP sockets.

Unlike traditional client-server applications, this system
does not depend on a central server.

Every peer can communicate directly with other peers.

## Project Objectives

1. Implement UDP socket communication.
2. Support communication between at least four peers.
3. Implement automatic peer discovery and membership.
4. Develop reliable and ordered group messaging.
5. Implement acknowledgements and retransmissions.
6. Support distributed file storage using chunks.
7. Replicate each file chunk on at least two peers.
8. Implement parallel downloads from multiple peers.
9. Handle peer failures during file transfers.

## Technologies

- Python 3
- UDP Sockets
- Multithreading
- Git and GitHub
- Ubuntu Linux (WSL)
- Visual Studio Code

## Development Approach

The project will be developed incrementally.

Each feature will be implemented, tested, and committed
to Git before proceeding to the next feature.
